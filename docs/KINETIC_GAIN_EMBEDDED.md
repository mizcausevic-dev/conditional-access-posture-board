# Kinetic Gain Embedded Tie-Back

This repo demonstrates the Conditional Access control-plane primitive of Kinetic Gain Embedded:

- policy-bundle visibility
- admin enforcement and exclusion hygiene
- device-trust and sign-in-risk cleanup
- app targeting and exception posture

For embedded product work, the same primitive becomes an in-app identity-governance panel where operators need evidence-rich surfaces without direct access to raw admin portals or tenant credentials.
